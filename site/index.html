Request path

How requests are checked

One proxy applies the same cooldown before a package reaches a developer or CI job.

  1. 01

    Point clients at the proxy

    Use the npm, PyPI, or Cargo registry URL in client configuration.

  2. 02

    Check release age

    The proxy compares publish time with your configured cooldown.

  3. 03

    Return a decision

    Allowed versions download. Blocked versions receive a recorded response.

Limits and privacy

What the proxy does not do

It does not host private packages, authenticate users, or scan package code. Protect the cache and refusal log on your own host.
